# Security Policy

## Supported Versions

This repository is intended for **educational and research purposes**.
It is not designed for production deployment.

Security updates are provided on a best-effort basis.

---

## Reporting a Vulnerability

If you discover a security issue:

- Do **not** open a public issue
- Use **GitHub Security Advisories** instead
- Provide a clear description and reproduction steps

---

## Expected Usage

This repository:

- Does NOT require production credentials
- Should NOT contain API keys or secrets
- Uses local models and local data by default

Do not commit:
- API keys
- Tokens
- Credentials
- Private datasets

---

## Threat Model

This repo assumes:
- Local execution
- Trusted user
- No exposed network services

Any extension beyond this is at the user's discretion.

---

Thank you for practicing responsible disclosure.
