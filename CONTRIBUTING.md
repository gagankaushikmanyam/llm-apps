# Contributing to LLM Lab

Thanks for your interest in contributing to **LLM Lab** 🎉

This repository is designed as a **learning and research lab** focused on
**inspectable, systems-first LLM engineering**.

We welcome contributions that align with this philosophy.

---

## Guiding Principles

When contributing, please prioritize:

- **Clarity over cleverness**
- **Inspectability over abstraction**
- **Educational value over performance hacks**
- **Explicit failure modes**

This is not a production framework — explanations matter as much as code.

---

## What You Can Contribute

Examples of valuable contributions:

- New applications under `applications/`
- Improvements to existing demos
- Bug fixes with explanations
- Documentation improvements
- Visualizations or debugging tools
- Performance comparisons with analysis

---

## Contribution Workflow

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Add comments or documentation where appropriate
5. Submit a pull request with a clear description

---

## Coding Style

- Prefer readable, explicit code
- Avoid unnecessary abstractions
- Keep dependencies minimal
- Comment non-obvious logic
- Make UI behavior explain *why*, not just *what*
