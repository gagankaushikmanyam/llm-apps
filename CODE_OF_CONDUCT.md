# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful,
inclusive, and harassment-free experience for everyone.

---

## Expected Behavior

- Be respectful and constructive
- Assume good intent
- Give thoughtful feedback
- Respect different levels of experience
- Focus on ideas, not individuals

---

## Unacceptable Behavior

- Harassment or discrimination
- Trolling or insulting language
- Personal attacks
- Publishing private information without consent

---

## Enforcement

Project maintainers are responsible for enforcing this code of conduct.
They may remove content or restrict participation if necessary.

---

## Scope

This code applies to:
- GitHub issues
- Pull requests
- Discussions
- Any project-related communication

---

## Acknowledgment

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/),
